# 路径规划：UF（化工）→ 清华 → 比现在更好的工作

截至 2026-07-02 的状态：正在转学去 UF，专业为化学工程，目前在修微积分 1（8 门先修课中的第 1 门）。

## 先说实话

化工专业 + 一套能实际运行的量化交易系统，是一个不常见但真实存在的组合：懂编程的过程工程师在大宗商品/能源交易（实物+金融）领域很有价值，而量化机构有时也想要那种懂实体市场（航运、咽喉要道、炼油）的人，而不是纯数学博士。你在 `alt_macro.py` 里做的咽喉要道分析（霍尔木兹海峡/红海/油轮航运数据）本质上是一种化工背景衍生出来的技能，是任何 CS 训练营出身的人都不会有的。不要把化工学位藏起来——要把"实体市场 + 量化基础设施"当作自己的差异化定位，主动去讲。

## 阶段一 — UF 先修课（现在 → 约 18-24 个月）

课程顺序很重要，既是为了保持学习节奏，也是为了能和项目工作搭配起来：

1. **微积分 1（当前）** → 微积分 2 → 微积分 3 → 微分方程。这些也是任何量化方向（随机微积分、期权定价用的偏微分方程）字面意义上的数学先修课。
2. **普通化学 1/2** —— 化工专业的标准要求，和 bot 项目没有交集，当作必须打钩完成的任务高效处理即可。
3. **物理 1/2（微积分基础）** —— 物理 1（力学）有实际的知识交叉：流动性门控（liquidity-gate）的 z-score 逻辑和状态衰减（regime decay）数学，本质上和物理里"变化率/守恒"的思维方式是一样的。可以把物理课当作练习"把真实系统翻译成微分方程"的场地——这直接可以迁移到你的 `HalfLifeDecay`（λ = ln2/半衰期）那部分工作上。
4. **静力学**（化工/机械工程要求）—— 与量化交叉最少，当作必须打钩完成的任务处理。
5. 第 8 门课，随便哪门通识/写作课都可以填——但如果你在选课上有任何自由度，建议用一门入门**统计学**或**线性代数**课来代替纯通识课；这对 UF 申请（能体现量化倾向）和 bot 项目本身都有不成比例的高回报。

**先修课阶段的并行任务：** 不要等到进了 UF 才开始打造简历里"量化"的那一面。参见 [[04_bot_master_guide]] 和 [[02_quant_evaluation_criteria]]——利用修先修课这段时间，把现有的 bot 打磨成一个经过回测、有完整文档、有真实业绩数字的系统。这个成果对求职的意义，比你微积分 1 拿了多少 GPA 更重要。

## 阶段二 — 在 UF 期间（化工专业）

- **可叠加的辅修/证书：** UF 通过沃靈頓商学院（Warrington College of Business）提供一条类量化金融的路径（金融类选修课通常对非商科学生开放，可作为自由选修课），另外数学/统计系有统计学辅修。对于瞄准量化/交易岗位的化工专业学生来说，统计学辅修是杠杆最高的加分项——当主修专业不是数学/CS/金融时，这正是招聘方会重点扫的那一行简历。
- **目标选修课，按优先级排序：** 概率与统计（微积分基础）→ 线性代数 → 一门编程入门/数据结构课程（哪怕是"面向工程师"版本也行）→ 数值方法（化工专业通常都有这门课——这是你的桥梁课程，本质上解的就是定价模型要用到的那些常微分方程/偏微分方程）→ 如果商学院允许跨院选课，再加一门衍生品/投资类选修课。
- **科研/实验室角度：** 化工系通常都有过程控制/系统实验室（PID 控制器、反馈回路）。去这类实验室做志愿者/参与研究，是一条能直接映射到你的流动性门控和状态重置逻辑的简历亮点——控制理论和交易系统的风险门控本质上是同一套数学（反馈、阈值、滞后）。这在面试里会是一个很好的谈资："我为订单执行做了一个类似控制回路的中止机制，这是我学到背后理论的那门过程控制课。"
- **整个过程中持续打磨 bot**，把它作为你唯一一条持续积累的作品线——一个非平凡系统 3-4 年的持续开发历史，比每学期都做一个新的课程项目更有说服力。

## 阶段三 — 清华（研究生阶段）

从 UF 化工学位进入清华的现实路径：
- **清华-伯克利深圳学院（TBSI）** 或 **清华经管学院（SEM）** 的硕士项目（比如量化金融硕士，或偏金融工程方向的项目）——这些项目会接受数学/工程背景扎实、但本科非金融专业的强申请者，只要申请材料能展示出数学能力和实际的量化项目经验。你的 bot 恰好就是化工背景的成绩单本身欠缺的那份"量化实战经验"证明。
- **清华化学工程系**的研究生项目也是一个选项，如果你想保留化工这条线，之后再转向大宗商品/能源交易（像托克（Trafigura）、维多（Vitol）、嘉能可（Glencore）这类公司的实物交易台明确青睐既懂化工/过程工程、又懂衍生品的毕业生——这是一条比纯量化金融更小众、竞争也更小的交易岗位路径）。
- **中文要求：** 清华大部分英文授课的硕士项目（SEM 的国际项目）并不要求中文流利，但 HSK 4-5 级会大幅拓宽选择面，而且如果之后打算在中国工作，这一点也很关键。
- **申请筹码：** GRE/GMAT 的数学分数，以及一份能明确把"搭建了一套横跨美股和中国市场的实盘多市场交易系统"（你有一个中国市场数据引擎——记得提到你专门研究过中国市场结构）和"为什么清华/中国市场专长对你很重要"联系起来的强 SOP。这是一个真正与众不同的故事线——大多数申请者都没有一套已经涉足中国股票市场的实际运行系统。

## "在毕业之前就找到比现在更好的工作"具体是什么样子

你不需要等到清华，甚至不需要等到 UF 学位拿到手，才能找到一份比现在更好的工作。具体的近期目标见 [[06_job_leads_remote_jax]]。现实的顺序是：
1. 现在 → 未来 6-12 个月：用这个 bot（按照 [[04_bot_master_guide]] 完成回测、文档化、达到面试可展示的状态）去争取一份**初级/远程的交易基础设施、数据工程，或量化开发相关的岗位**——这不需要一个完整的学位，只需要能拿得出手的实际成果。
2. 在 UF 就读期间：保住这份工作或类似的工作，兼职/远程做，同时完成先修课和学位，随着简历不断加分逐步升级岗位。
3. 清华阶段：把这段经历当作跳向研究方向或更高级量化岗位的学历跳板，或者作为转向面向中国的交易/大宗商品岗位的转折点——如果"化工转实体市场"这条线正是你想走的方向。
