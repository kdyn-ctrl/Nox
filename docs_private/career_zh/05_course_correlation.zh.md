# 课程 ↔ 机器人相关性图谱

在面试和求职申请中，用这个来把你的课程和项目讲成同一件事——两者的关联才是故事本身，而不是简历上两条互不相干的条目。

| 课程（UF 化工路径） | 对应的机器人组件 | 实际关联 |
|---|---|---|
| 微积分1（在读） | 信号衰减的变化率 | 导数就是"信号价值衰减速度"背后的原始数学——和 `HalfLifeDecay` 是同一个极限/速率概念。 |
| 微积分2 | 期权/隐含波动率偏斜的直觉 | 积分是期权偏斜解读中隐含使用的期望值计算的基础（分布曲线下的面积）。 |
| 微积分3（多元微积分） | 多因子融合（矛盾向量、另类宏观） | 组合多个独立信号（文本情绪 × 波动率偏斜、实物 × 政治因素）本质上是一个多变量问题——可以把它想成一个需要联合评估的多元函数。 |
| 微分方程 | 状态衰减与重置（WS4） | `HalfLifeDecay` 中 λ=ln2/半衰期，是一阶线性常微分方程的解（dN/dt = -λN）——和放射性衰变、一阶化学反应动力学是完全相同的方程。这是你最有力、最直白的"课程对应代码"的例子。 |
| 普通化学1/2 | 反应动力学类比 | 一级反应动力学（速率∝浓度）在数学上和你的信号衰减模型完全一致——可以直接拿这个类比来讲，即便对非技术面试官也是个很好的解释工具。 |
| 物理1（力学） | 流动性阀门/控制阈值 | z 分数中止阈值和预热期，本质上和物理习题中"系统对外部输入的响应，带有阈值/容差"的思路是一样的（比如失效前的应力、阻尼响应）。 |
| 物理2 | （关联较弱，属于间接） | 如果被问到物理相关性，可以泛泛地包装成"物理系统的定量建模"经验。 |
| 静力学 | （关联最弱——只是化工学位要求，不是机器人类比） | 完全可以只当作学位要求打个勾，不必强行找关联。 |
| 概率与统计（推荐选修） | 判定命中率评估、z 分数、回测夏普/索提诺比率 | 这是对 [[02_quant_evaluation_criteria]] 中"用数据证明"这个短板最直接、最有分量的一门课。优先修这门。 |
| 线性代数（推荐选修） | 多信号加权/未来的学习型集成模型 | 如果你按 [[02_quant_evaluation_criteria]] 第3项所说构建"学习型加权"升级，那本质上就是一个加权线性组合——直接对应这门课的内容。 |
| 数值方法（化工核心课，如果在你的培养方案里） | 回测引擎/衰减与状态模型的常微分方程求解 | 化工数值方法课程求解的正是同一类常微分方程（一阶衰减、方程组），用的也是同样的数值格式（欧拉法、龙格-库塔法），而你的衰减/状态代码正是用离散时间步长在近似这些方法。这是你能讲出的最有力的"这门课直接提升了我的项目"的故事。 |
| 过程控制/仪表（如果化工选修课或实验课里有） | 流动性阀门、状态重置锁存、故障开放式设计 | PID 控制、反馈回路、滞后特性、故障安全设计，正是你执行风控阀门已经在做的事情的工程学术语。如果 UF 有开这门课，一定要选——这是对这个项目杠杆最高的一门单科选修课。 |

## 如何使用这张表
- 在求职信或面试中，不要说"我学化工，同时也在做一个交易机器人"这种割裂的话。要说："我化工课程里学的反应动力学和常微分方程数值方法，和我交易系统信号衰减模型背后的数学是同一套东西——量化金融和化学工程对我来说从来不是两件互不相干的事。"
- 每学期根据你实际选的 UF 课程更新这张表——它应该追踪你真实、当前在修的课程，而不是泛泛罗列可能会修的课。
