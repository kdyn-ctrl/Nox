# Private Journal: June 16-18, 2026 — Starting Nox

*Private mirror of [docs/journal/2026_06_16_to_18_origins.md](../../docs/journal/2026_06_16_to_18_origins.md) with real specifics kept out of the public version.*

## Concrete detail

- Report truncation: `heartbeat/monitor.py`'s `run_scout_protocol()` called Claude with `max_tokens=4096` against a system prompt that said "do not truncate... complete every section fully" — a self-contradiction. Fixed 4096 → 16384 (June 16), then → 32768 (June 18) when it recurred as the report content grew (US headlines + SEC 8-K/6-K filings + China market data all landing in the same call). Also found `pyTelegramBotAPI` was 13 versions stale and the `anthropic` SDK predated Haiku 4.5's release — bumped both while in there.
- Webhook 400: `analyst/main.cpp:325` — `httplib::Client cli("execution-engine", 8080)` (host+port ctor) vs. `httplib::Client cli("http://execution-engine:8080")` (scheme+host+port ctor) for Docker-internal DNS resolution. One-line fix, verified via `docker logs nox_analyst` / `docker logs nox_execution` showing the delivery actually land.
- RULE-009 test (fail loud on missing required env var → `[FATAL]` + `exit(1)`) was drafted as a fork/pipe C++ test harness against the `require_env` lambda in `execution/main.cpp` but the session was interrupted before it ran. Worth checking whether this test exists and passes today before citing it in an interview.

## Interview angle

This is good "early habits" material for [[03_bot_interview_questions]] Tier 1 ("walk me through it") — not because anything here is impressive on its own, but because it shows the *first* instance of the "fix symptom, recur, fix root cause" pattern that repeats through the whole build. If asked "give an example of a mistake you learned from early on," the report-truncation fix (two undersized token-limit bumps before addressing that the prompt itself was contradictory) is a clean, low-stakes example to lead with before escalating to the June 28 incident.
