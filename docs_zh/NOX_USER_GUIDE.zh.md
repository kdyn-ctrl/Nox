# Nox 交易机器人 —— 用户指南

**本指南面向非技术用户，帮助你理解这个机器人在做什么、以及如何监控它。**

---

## Nox 是什么？

Nox 是一个**全自动交易机器人**，它会持续监控股票市场、做出交易决策，并自动下达买入/卖出订单。它主要交易 **SPY**（跟踪标普 500 指数的 ETF），并会仔细地管理风险。

**核心思路**：当市场条件有利时，它会买入；当条件转差时，它会卖出或观望。它会根据自己对这笔交易的信心程度来决定仓位大小（也就是买多少股）。

---

## Nox 是如何工作的？（简单版）

### 每日循环

在每个交易日的交易时段内，Nox 会执行以下流程：

```
1. WATCH（观察）: 检查当前市场状况
   ↓
2. ANALYZE（分析）: 判断现在是否是交易的好时机
   ↓
3. DECIDE（决策）: 生成买入或卖出信号
   ↓
4. VALIDATE（校验）: 再次确认该信号是安全的
   ↓
5. SIZE（定量）: 决定买入多少股
   ↓
6. EXECUTE（执行）: 通过 Alpaca（你的券商）下单
   ↓
7. REPORT（汇报）: 通过 Telegram 向你推送更新
```

### Nox 关注哪些指标？

**VIX** —— "恐慌指数"
- VIX 低（< 35）= 市场平静、信心充足 → 适合买入
- VIX 高（> 35）= 市场恐慌 → 更适合观望或卖出

**SPY 价格 vs. 200 日均线**
- SPY 高于均线 = 上升趋势 → 看涨信号
- SPY 低于均线 = 下降趋势 → 看跌信号

**市场机制（Market Regime，即当前所处的状态）**
- **RISK_ON**（绿色）：市场健康，VIX 低，SPY 强势 → 积极交易模式
- **TRANSITION**（黄色）：市场不确定 → 减小仓位规模
- **RISK_OFF**（红色）：市场处于危机状态，VIX 高，SPY 疲弱 → 停止交易，降低风险

---

## Nox 会冒多大的风险？

Nox 使用**凯利公式（Kelly Criterion）**——一个数学公式，用来决定每笔交易应该投入多少比例的资金。

**简单来说**：Nox 越有信心（基于历史胜率），仓位就越大。但它绝不会：
- 在单笔交易上冒超过投资组合总额 **10%** 的风险
- 在单笔交易上冒低于投资组合总额 **1%** 的风险

举例：
- 投资组合：10 万美元
- Nox 信心较高 → 8% = 每笔交易 8,000 美元
- Nox 信心较低 → 2% = 每笔交易 2,000 美元

## 各类提醒代表什么

你会收到 Telegram 推送通知。以下是它们各自的含义：

### 🟢 绿色提醒（正常）

**"📊 [ANALYST] Regime Classification"（市场机制分类）**
- Nox 刚刚完成了一次市场分析
- 显示当前的机制状态（RISK_ON、TRANSITION、RISK_OFF）
- 这在交易时段内会自动发生

**"✅ [EXECUTION] Order Submitted"（订单已提交）**
- 交易成功
- 显示标的（SPY）、股数、成交价
- 该订单现已在 Alpaca 中生效

### 🟡 黄色提醒（需留意）

**"⚠️ [MOMENTUM] Signal Blocked"（信号被拦截）**
- Nox 生成了一个信号，但将其拦截了
- 原因：RSI 过高（超买）或过低（超卖）
- Nox 在保护你，避免在高点买入或在低点卖出

**"⚠️ [REGIME] Reduced Position Size"（仓位缩减）**
- 市场进入了 TRANSITION（过渡）机制
- Nox 正在以比平时更小的仓位交易（更安全）
- 在市场不确定期属于正常现象

### 🔴 红色提醒（问题）

**"🔴 [CRITICAL] Regime Changed to RISK_OFF"（机制切换为 RISK_OFF）**
- 市场刚刚转差（VIX 飙升或 SPY 暴跌）
- Nox **已停止交易**以保护你的资金
- 请查看新闻——可能发生了重大事件

**"🔴 [CRITICAL] Portfolio Check Failed"（账户检查失败）**
- Nox 无法通过 Alpaca 核实你的账户余额
- 可能原因：网络问题、API 中断，或券商问题
- Nox 会自动重试

**"🔴 [CRITICAL] Order Failed"（订单失败）**
- 交易未能成交
- 原因不一：购买力不足、市场熔断、券商故障等
- Nox 会通知你，并等待下一次机会

### 📋 信息类提醒

**"📈 Market Intelligence Report"（市场情报报告）**
- 当日交易活动汇总
- 显示：当前机制、已执行的交易、账户价值变化
- 自动发送（通常每天一次）

## 可能出现哪些问题？

### Nox 没有交易
**可能的原因**：
- 交易时段限制：Nox 只在周一至周五 9:30am–4:00pm（美东时间）交易
- 机制为 RISK_OFF：市场条件不佳，Nox 在等待
- 信号被拦截：VIX 过高或过低（Nox 出于谨慎）

**应对方法**：查看最新的 Telegram 提醒，通常会说明原因。

### Telegram 提醒停止了
**可能的原因**：
- Bot token 失效或被撤销
- Chat ID 错误
- 网络连接中断

**应对方法**：请技术负责人核实 Telegram token 并重启机器人。

### 订单持续失败
**可能的原因**：
- Alpaca 账户购买力不足
- 市场熔断（通常发生在重大新闻之后）
- Alpaca API 宕机
- 网络连接不佳

**应对方法**：检查你的 Alpaca 余额，如果偏低就充值；如果是 Alpaca API 宕机，则等待恢复。

### Nox 在 RISK_OFF 状态下仍持续交易
**这种情况不应该发生。** 如果发生了：
- 说明 Nox 检测到了市场危机，却仍然下了单
- 这属于一个 bug

**应对方法**：立即停止机器人，并联系你的技术负责人。

## 理解业绩表现

### 胜率（Win Rate）
- **含义**：盈利交易占总交易数的比例
- **良好**：50% 以上（比抛硬币更好）
- **优秀**：60% 以上（Nox 表现出色）
- **示例**：12 笔交易，7 胜 5 负 = 58% 胜率

### 平均盈利 vs. 平均亏损
- **良好**：平均盈利至少是平均亏损的 1.5 倍
- **示例**：平均盈利 +200 美元，平均亏损 -100 美元（2:1 的比率非常好）

### 总盈亏（P&L）
- **最重要的数字**：你的账户是增长了还是缩水了
- Nox 的目标是让账户缓慢而稳定地增长
- 不要期待月化 +20%；在条件良好时，预期月化 +1% 到 +3% 较为合理

### 夏普比率（Sharpe Ratio，进阶指标）
- **含义**：风险调整后的收益（收益相对于波动性的比值）
- **良好**：1.0 以上（稳定盈利，波动不大）
- **优秀**：2.0 以上（非常稳定、可预期的增长）


之后，当中国散户媒体发现该信息时：

```
🔔 [WS7] LAG WINDOW CLOSED — BABA
Source: East Money
Lag: 4.2h since 6-K filing
```

滞后时间越长，说明这种信息不对称存在的时间也越长。

## Nox 什么时候交易？

### Nox 处于活跃状态
- 📅 **交易日**：周一至周五（不含周末/节假日）
- ⏰ **交易时段**：美东时间上午 9:30 至下午 4:00
- 📊 **前提条件**：市场机制不是 RISK_OFF

### Nox 处于非活跃状态
- 🔴 周末及美国市场假日
- 🔴 开盘前（美东时间 9:30 之前）
- 🔴 收盘后（美东时间 4:00 之后）
- 🔴 当机制为 RISK_OFF（市场危机模式）时

## Nox 遵循的关键规则

1. **始终确认投资组合价值** —— 在下任何订单之前，Nox 都会通过 Alpaca 核实你的账户余额。如果无法确认，它就不会交易。

2. **单笔交易风险绝不超过 10%** —— 即便计算结果建议更大的仓位，Nox 也会将其限制在投资组合的 10% 以内。

3. **绝不以 0 股进行交易** —— 如果计算出的仓位小于 1 股，Nox 会取消该笔交易。

4. **拦截超买/超卖信号** —— 如果 RSI（动量指标）显示市场处于极端状态，Nox 会拦截该信号，以避免在高点买入。

5. **危机中停止交易** —— 当 VIX 飙升或 SPY 大幅暴跌时，Nox 会切换到 RISK_OFF 状态并立即停止交易。

6. **对所有交易进行身份验证** —— 每一笔订单都必须携带正确的密钥（secret key），否则订单会被拒绝。

## 常见问题（FAQ）

**问：在 Nox 运行期间，我能手动交易吗？**
答：可以，但请谨慎。你的手动订单会和 Nox 的订单同时执行，这可能导致仓位过度集中或出现意料之外的风险。

**问：如果我不喜欢 Nox 做出的某笔交易怎么办？**
答：你可以在 Alpaca 中手动平仓。Nox 发现该持仓消失后，如果条件合适会重新生成新的交易。但请记住：Nox 之所以做出那笔交易，是基于数学上的理由；手动平仓可能会锁定亏损。

**问：Nox 交易期权或使用杠杆吗？**
答：核心的股票机器人只交易整股。期权信号现已作为独立的顾问通道提供——详见下方的"期权信号生成器"章节。

**问：如果 Nox 运行期间市场崩盘了会怎样？**
答：Nox 会切换到 RISK_OFF 机制并停止交易。它不会自动卖出现有持仓（那样做会锁定亏损），而是会静候市场恢复平静。

**问：我应该多久检查一次 Nox？**
答：如果 Telegram 提醒工作正常：收到推送时查看即可。如果 Telegram 不工作：每天检查一次 Alpaca 仪表盘。Nox 不需要时刻盯着。

**问：Nox 会亏光我所有的钱吗？**
答：它的设计初衷就是要避免这种情况。10% 的仓位上限和凯利公式仓位管理能防止灾难性亏损。但任何交易都有风险，Nox 是一个机器人，不是保证。

**问：如果发现有些地方不对劲，我该怎么做？**
答：首先，查看 Telegram 是否有错误提醒；其次，去 Alpaca 核实订单是否合理；最后，联系你的技术负责人。Nox 的设计理念是"宁可大声报错，也不悄无声息地出问题"。

## 为什么我收不到交易信号？

这是最常见的操作性问题。以下是诚实的答案：

### 股票信号的实际运作方式

执行引擎**并不会**自主生成股票的买入/卖出信号，它只是一个接收端。完整的流程如下：

```
TradingView 策略触发一条警报
        ↓
TradingView 向你的 VPS 发送一条 JSON webhook（端口 80/443 → 执行引擎的端口 8080）
        ↓
执行引擎验证信号，检查市场机制，计算仓位大小
        ↓
向 Alpaca 下单
```

**分析代理（analyst agent）只会发送 `REPORT`（报告）类型的信号。** 它会告诉你当前的市场机制（RISK_ON / RISK_OFF），但不会发送 BUY 或 SELL 信号，只有 TradingView 才会发出这类信号。

如果你已经好几个月没收到交易信号了，那么很可能是以下原因之一：

---

### 诊断清单——请按顺序逐项排查

**第一步：TradingView 是否在发送 webhook？**
- 登录 TradingView → 打开你的策略 → 进入 Alerts（警报）页面
- 检查是否存在警报，以及该警报是否处于**激活**状态（绿点）
- TradingView 免费版的警报在一段时间后会过期。如果警报显示为灰色或已被删除，说明它早已停止发送
- **解决方法：** 在该 Pine Script 策略上重新创建警报，将触发方式设置为 `Once Per Bar Close`（每根K线收盘时一次），并填入你的 webhook URL

**第二步：webhook URL 是否正确？**
- webhook 目标地址应为 `https://<你的域名或IP>/webhook`（如果没有 SSL 则为 `http://`）
- 如果你的 VPS IP 发生了变化，该 URL 就会失效
- **解决方法：** 将 TradingView 警报中的 URL 更新为当前服务器地址

**第三步：执行引擎是否确实在运行？**
- 在你的 VPS 上执行：`docker-compose ps`
- 应该能看到 `execution-engine` 的状态为 `Up`
- **解决方法：** 执行 `docker-compose up -d execution-engine`

**第四步：是否被机制门控拦截了？**
- 当 `RISK_OFF` 生效时，机制门控会拦截所有新的 BUY 订单
- 当 VIX ≥ 35 或 SPY 较其 200 日均线低超过 2% 时，会触发 RISK_OFF
- 在 2025 至 2026 年的大部分时间里，受宏观波动影响，机制状态一直在 RISK_ON 和 TRANSITION 之间切换
- **检查方法：** 查看你最新的 Telegram 分析报告——当时报告的是哪种机制？
- **在 TRANSITION 状态下：** 信号可以通过，但仓位规模会被削减 50%
- **在 RISK_OFF 状态下：** 所有 BUY 信号都会在执行环节被硬性拦截

**第五步：是否被 RSI 门控拦截了？**
- 当 RSI < 30（深度超卖，可能是"接落刀"）时，机器人会拦截 BUY 信号
- 在极端抛售期间，该门控可能会频繁触发
- **检查方法：** 如果是这个原因，Telegram 应该会显示 `🚧 RSI GATE BLOCK` 消息

**第六步：Pine Script 策略是否根本没有生成任何信号？**
- 打开你的 TradingView 图表，查看该策略的资金曲线
- 如果近期 K 线上没有出现新的三角形标记（买/卖标记），说明策略没有触发
- 这意味着当前市场状况不符合入场规则——机器人正在按预期工作，只是在耐心等待
- **该怎么办：** 参见下方的"应对方案"章节

### 应对方案——如果没有信号但你希望保持活跃

机制门控和 RSI 门控的存在是有原因的：在恶劣的市场条件下强行交易会侵蚀本金。如果条件不合适，正确的做法**不是**绕过这些门控，而是：

**方案 A：使用期权信号生成器（现已可用）**
期权信号生成器在后台线程中独立运行，默认每 30 分钟扫描一次（可配置）。它不需要 TradingView。一旦引擎启动，它就会自动生成顾问性质的 Telegram 提醒。在 RISK_OFF 机制期间，做多权利金（long premium）的信号会被抑制，但收入型策略（现金担保看跌期权、备兑看涨期权）仍会照常生成——这类策略反而能从高波动率中获益。详见下方的"期权信号生成器"章节。

**方案 B：核实并重新连接 TradingView**
1. 检查 TradingView 警报状态（见第一步）
2. 如果策略没有触发，检查 Pine Script 的条件设置——EMA 交叉 + 成交量过滤条件可能在当前市场结构下没有满足触发要求
3. 可以考虑调整策略的时间周期，或将该策略应用到更多标的上（webhook 请求体只需要一个 `ticker` 字段，并没有写死为 SPY）

**方案 C：使用模拟交易开发新信号**
如果你想在不承担真实资金风险的情况下构建新策略：
1. 在你的 `.env` 中设置 `ALPACA_BASE_URL=https://paper-api.alpaca.markets`
2. 将新的 TradingView 策略指向模拟交易端点进行测试
3. 运行 30–60 天以验证信号质量，然后再切换到实盘

**方案 D：观察机制并等待**
每天查看分析代理的 Telegram 报告。当机制恢复到 RISK_ON 且 VIX 降到 35 以下时，门控就会打开，信号将恢复正常执行。在 TRANSITION 状态下，较小规模的信号仍会以 50% 的仓位通过。

## 期权信号生成器

这是一套全新的、内置于执行引擎中的自成体系的顾问系统。与股票信号不同，**它不需要 TradingView**。它按计时器运行，并直接向你推送 Telegram 提醒。

### 它的功能

默认每 30 分钟（可配置），它会扫描一份标的观察列表，并基于以下要素生成期权交易构想：
- **标的技术面**：来自 Yahoo Finance 的 RSI、ATR、20 日均线、50 日均线
- **隐含波动率百分位（IV Rank）**：当前期权相对于过去一年而言是贵还是便宜
- **宏观机制**：与股票机器人相同的 VIX + SPY 机制门控

### 理解资金分层（Capital Tiers）

该生成器会根据你的账户规模自动调整所推荐的策略：

| 分层 | 资金规模 | 你能获得的功能 |
|------|---------|-------------|
| **STARTER（入门）** | 5,000 美元以下 | 仅提供买入看涨/看跌期权（Long Call/Put）。风险有限——最多只会亏掉你付出的权利金 |
| **STANDARD（标准）** | 5,000 – 30,000 美元 | + 现金担保看跌期权（CSP）和备兑看涨期权（Covered Call）。这类收入型策略利用你已持有的资产 |
| **ADVANCED（进阶）** | 30,000 – 75,000 美元 | + 垂直价差、跨式、宽跨式组合。风险有限，资金使用效率更高 |
| **FREE_CAPITAL（自由资金）** | 75,000 美元以上，或自定义 | 解锁全部策略。计算基于你指定的资金数额 |

该分层会根据你在 Alpaca 的实盘账户权益自动读取。如果你想单独划出一笔资金专用于期权（比如 1 万美元，与机器人自己的资金分开），可以在 `.env` 中设置 `OPTIONS_FREE_CAPITAL_AMOUNT=10000`——这会完全覆盖期权信号生成器对 Alpaca 权益的检查。

### 自由资金（Free Capital）模式

自由资金模式适用于你想让信号生成器基于你自己掌控的某个特定资金额度运行，而不是使用机器人在券商的账户余额。适用场景包括：
- 你在另一个账户（如 TD、IBKR、Robinhood）中有一笔资金，由你手动交易
- 你想用一个假设的 2 万美元虚拟资金来模拟期权构想，而你真实的机器人账户只有 5,000 美元
- 你拥有 10 万美元以上的资金，想解锁全部策略，但又不想将其与机器人的 Alpaca 余额绑定

启用方法：在 `.env` 中添加 `OPTIONS_FREE_CAPITAL_AMOUNT=<你的金额>` 并重启。

### 如何解读一条期权信号提醒

```
📊 OPTIONS SIGNAL — AAPL [STANDARD]
────────────────────────────────────
🎯 Strategy: Bull Call Spread
📅 Expiry: 2026-08-15 (53 DTE)
💵 Strikes: $195 / $200 Call
💰 Entry: $1.85 | Max Risk: $185 | Max Gain: $315
📊 R:R Ratio: 1.7:1
⚖️ Breakeven: $196.85

📐 Greeks
• Delta: +0.42 | Gamma: 0.019
• Theta: -$0.04/day | Vega: +0.31
• IV Rank: 24% ← LOW (buy premium zone ✅)

📈 Technicals — AAPL
• RSI(14): 52 | ATR(14): $2.31
• Price vs 20-SMA: ✅ above | vs 50-SMA: ✅ above

🌐 Macro Regime: RISK_ON ✅ (VIX 16.4, SPY > 200-SMA)
🎯 Signal Confidence: 87%

⚠️ Advisory only — manual execution required.
```

**各字段含义：**

| 字段 | 含义 |
|-------|------------------|
| **Strategy（策略）** | 该笔交易属于哪种期权策略 |
| **Expiry / DTE（到期日 / 剩余天数）** | 期权何时到期。DTE = Days To Expiration（距到期天数） |
| **Strikes（行权价）** | 你将以哪个（些）价格进行交易 |
| **Entry / Max Risk / Max Gain（入场价 / 最大风险 / 最大收益）** | 该笔交易的成本与上下限。Max Risk 是你最多可能亏损的金额 |
| **R:R Ratio（收益风险比）** | 1.7:1 表示每承担 1 美元风险，可获得 1.70 美元收益 |
| **Breakeven（盈亏平衡点）** | 股价需要达到的水平，你才不会亏损 |
| **Delta（德尔塔）** | 标的每变动 1 美元，期权价格随之变动的幅度。+0.42 表示股价每涨 1 美元，期权价值增加 0.42 美元 |
| **Theta（西塔）** | 每日时间损耗——期权仅因时间流逝每天贬值多少 |
| **Vega（维伽）** | 对波动率的敏感度。为正值表示波动率上升时该头寸受益 |
| **IV Rank（隐含波动率百分位）** | 当前期权相对贵还是便宜（0–100）。数值低=便宜；数值高=昂贵 |
| **Confidence（信心度）** | 经机制调整后的评分。低于 50% 表示市场状况不明朗 |

### IV Rank——最重要的数字

- **IV Rank < 30%** → 期权**便宜** → 适合买入权利金（看涨/看跌期权、价差组合、跨式组合）
- **IV Rank > 50%** → 期权**昂贵** → 适合卖出权利金（现金担保看跌期权、备兑看涨期权、宽跨式组合）
- **IV Rank 30–50%** → 中性区间 → 适合价差策略或观望

在 RISK_OFF（高 VIX）期间，IV Rank 通常偏高，这正是运用收入型策略的好时机——你可以收取较高的权利金。

### 策略术语表

| 策略 | 是什么 | 适用场景 |
|----------|-----------|---------------|
| **Long Call（买入看涨期权）** | 购买以行权价买入 100 股的权利 | 看涨，期权便宜时 |
| **Long Put（买入看跌期权）** | 购买以行权价卖出 100 股的权利 | 看跌，期权便宜时 |
| **Cash-Secured Put，CSP（现金担保看跌期权）** | 卖出看跌期权并持有现金以备被行权买入股票 | 看涨/中性，期权昂贵时。良好的收入策略 |
| **Covered Call，CC（备兑看涨期权）** | 针对你已持有的股票卖出看涨期权 | 中性/略偏空，期权昂贵时。可降低持仓成本 |
| **Bull Call Spread（牛市看涨价差）** | 买入一份看涨期权，卖出更高行权价的看涨期权 | 看涨，风险和成本均有限 |
| **Bear Put Spread（熊市看跌价差）** | 买入一份看跌期权，卖出更低行权价的看跌期权 | 看跌，风险和成本均有限 |
| **Long Straddle（跨式组合）** | 以相同行权价同时买入看涨期权和看跌期权 | 中性——预期会有大幅波动，方向不定。适合低波动率时买入 |
| **Long Strangle（宽跨式组合）** | 买入价外看涨期权和价外看跌期权 | 中性——与跨式类似，但更便宜，需要更大的波动幅度才能获利 |

### 配置项

以下配置项写在你的 `.env` 文件中：

| 变量 | 默认值 | 作用 |
|----------|---------|-------------|
| `OPTIONS_WATCHLIST` | `SPY,QQQ,AAPL,TSLA,NVDA` | 要扫描的标的列表，用逗号分隔 |
| `OPTIONS_SCAN_INTERVAL_MINUTES` | `30` | 扫描运行的频率 |
| `OPTIONS_FREE_CAPITAL_AMOUNT` | _（默认关闭）_ | 自由资金模式所用的金额。设置为一个数字即可启用 |

### 重要提示：仅供参考，不会自动执行

这些信号**仅供你手动审阅和执行**。机器人不会自动下达这些期权交易订单。是否采纳每一条信号、何时入场、如何管理仓位，都由你自行决定。

信号会为你提供经过量化分析支撑的交易构想，但是否符合你的判断、你的券商条件以及你的时间安排，需要你自己来决定。

## 开发你自己的信号

如果你想构建新的交易策略并将其接入机器人：

### 使用 TradingView + Pine Script（股票交易）

1. 在 TradingView 上编写或找到一个 Pine Script 策略
2. 在图表上进行测试——寻找信号稳定、不会频繁反复的策略
3. 添加警报：`Condition: Order fills`（条件：订单成交）→ Webhook URL：填入你的服务器地址
4. webhook 请求体必须符合以下格式：
```json
{
  "secret_key": "your_WEBHOOK_SECRET_TOKEN",
  "ticker": "AAPL",
  "action": "BUY",
  "price": 195.50,
  "rsi": 54.2,
  "atr": 2.31,
  "vol": 45000000,
  "stop_loss_atr_multiplier": 2.0,
  "risk_tier": 0,
  "vix": 16.4,
  "spy_price": 580.0,
  "spy_200_sma": 565.0
}
```
5. 机器人会完成校验、定量并执行，你会收到 Telegram 确认消息。

### 使用模拟交易进行验证

在任何新策略上线实盘之前：
1. 设置 `ALPACA_BASE_URL=https://paper-api.alpaca.markets`
2. 在 TradingView 上运行该策略，并指向你的服务器
3. 监控 Telegram 上的信号，并检查 Alpaca 的模拟交易仪表盘
4. 经过 30–60 个交易日后，检查胜率和盈亏情况
5. 只有当模拟交易结果表现稳健时，才切换到实盘

### 信号接入管道是开放的

`/webhook` 接口可以接受来自任何来源的信号——不局限于 TradingView。你可以从一个 Python 脚本、一个 Jupyter notebook、另一个服务，或任何能够发出 HTTP POST 请求的程序发送信号。唯一的要求是携带正确的 `secret_key` 以及上述各字段。
